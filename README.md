# Fútbol Total

## Descripción
Sitio web de una escuela de fútbol desarrollado para la práctica
"Aplicación de estilos y propiedades CSS".

## Tecnologías utilizadas
- HTML5
- CSS3
- Git
- GitHub

## Funcionalidades
- Presentación de la escuela.
- Navegación entre secciones.
- Tabla de posiciones.
- Galería de imágenes.
- Formulario de contacto.
- Sección de próximos partidos.

## Estructura del proyecto
- index.html
- css/estilos.css
- imagenes/
